This branch holds Entanglix releases. It is neither a research workspace nor a place for development instructions.

- To install Entanglix and set up a research project, follow [README.md](README.md#install). Research runs in a project directory prepared by `entanglix setup-project`, which copies the research conduct and skills and configures access to the MCP server; do not run research from this clone.
- Changes to Entanglix are made on the `development` branch, whose `AGENTS.md` gives the development instructions.
